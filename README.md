# 3D Model Catalog & Gallery Hub 🚀

Сучасний веб-сайт-галерея для 3D моделей, розроблений на Flask, SQLite та Tailwind CSS з підтримкою WebGL 3D перегляду (Google `<model-viewer>`).

## ✨ Реалізовані можливості

1. **Окрема вкладка галереї (`/gallery`)**:
   - Окремий розділ для перегляду всіх 3D моделей у каталозі у вигляді карток.
   - Відображення кількості фотографій у галереї кожної моделі (бейдж 📸 N фото).
   - Сортування: за новизною, кількістю переглядів, назвою.
   - Фільтрація за категоріями та тегами.

2. **Блок «Нещодавно додані моделі» на головній сторінці (`/`)**:
   - Преміальний блок на головній сторінці, де відображаються останні завантажені моделі.
   - Індикатори форматів (GLB, OBJ, STL тощо).
   - Швидкий перехід до 3D перегляду та галереї фотографій.

3. **Форма «Додати модель» з можливістю завантаження фотографій для галереї (`/add`)**:
   - Поля: Назва, Категорія, Детальний опис, Теги, Кількість полігонів, Автор.
   - Завантаження файлу 3D моделі (`.glb`, `.gltf`, `.obj`, `.stl`, `.fbx`, `.blend`).
   - Завантаження основної обкладинки для картки.
   - **Мульти-завантаження фотографій галереї (`gallery_photos`)**: вибір кількох фотографій одночасно з миттєвим попереднім переглядом перед відправкою форми.

4. **Пошук за назвою або тегом моделі**:
   - Глобальний пошук у шапці сайту з живими підказками (Live Autocomplete).
   - Пошуковий рядок у вкладці Галереї з підтримкою пошуку за назвою, тегами, описом або категорією.
   - Інтерактивна хмара популярних тегів: натискання на будь-який тег миттєво фільтрує галерею.

5. **База даних для збереження моделей (SQLite `models.db`)**:
   - Таблиця `models`: зберігає ID, назву, опис, категорію, теги, обкладинку, шлях до 3D файлу, формат, розмір, полігони, автора, лічильник переглядів, дати створення та оновлення.
   - Таблиця `model_photos`: зберігає індивідуальні фотографії для галереї кожної моделі зі зв'язком `FOREIGN KEY ON DELETE CASCADE`.
   - Початкове автозаповнення якісними 3D моделями та рендерами для демонстрації.

6. **Інтерактивний 3D переглядач та повноекранний лайтбокс фотографій**:
   - Повноцінний WebGL 3D перегляд GLB/GLTF моделей з обертанням, зумом, авто-обертанням, зміною ракурсу та повноекранним режимом.
   - Фотогалерея на сторінці моделі з модальним вікном (лайтбоксом) для гортання фото стрілками клавіатури або кнопками.

## 🛠 Запуск проекту

### Швидкий запуск на Windows:
Просто двічі клацніть файл **`run.bat`**.

### Або через термінал PowerShell / CMD:
```powershell
python -m pip install -r requirements.txt
python seed_data.py
python app.py
```

Після запуску відкрийте браузер за адресою:
👉 **http://127.0.0.1:5000**
